- Desktop builds check for updates only when their release configures a Pairdraw update feed; other builds say updates aren't set up instead of offering OpenPencil releases.
- Release downloads are named Pairdraw_* instead of OpenPencil_*.
- The sticky note tool shows in the design toolbar by default, without a key, so N still zooms to the next frame.
- ⇧⌘K (Ctrl+Shift+K) now places an image, as in Figma; Create Component Set no longer has a shortcut and is in the context menu.
- The pixel grid stays shown or hidden across documents and sessions, and Settings → Editor has a Show pixel grid switch.
- Breaking a path at a point with Option/Alt+Delete keeps the curves' handles and the fills the break leaves closed.
- Reopening a chat conversation selects the model it last used, when that model can continue it.
- Exporting several selected layers to PDF makes one PDF with a page per layer, in the order they were selected.
- HTML export writes each layer's name as a data-name attribute and leaves layer IDs out unless asked; the CLI takes --no-layer-names and --layer-ids.
- Vue and React code in the Code panel draws icons from an icon set as Iconify components, as the Storybook export does, instead of as inline vectors.
- Convert to vector keeps the original image and places the editable vectors in a new frame beside it, without changing the group, auto layout, mask or component that holds the image.
