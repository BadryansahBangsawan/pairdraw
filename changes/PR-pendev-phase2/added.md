- Hold Z for the zoom tool: click to zoom in, Option/Alt-click to zoom out, or drag to zoom to an area; tap Z, or pick Zoom from the Hand tool's toolbar menu, to keep it on.
- Press K for the Scale tool, which scales layers with their text, strokes, effects, corner radii, and spacing from a selection handle (Option/Alt from the center), or by a typed width, height, or factor from an anchor grid in the Design panel; several selected layers scale together.
- Moving a layer snaps to equal spacing between its neighbors, horizontally and vertically, and shows each matching gap with its size.
- Vector edit mode bends a segment when you drag it with Cmd/Ctrl, and with Cmd/Ctrl+Alt bends it without moving the neighbouring handles; the shortcut sheet lists both gestures.
- Selecting two or more points or segments in vector edit mode shows a transform box that scales them from a corner or edge (Shift keeps proportions, Alt scales from the centre) and rotates them from just outside a corner (Shift snaps to 15°).
- Text can link to web pages and email addresses: add, edit, or remove a link on a whole text or on selected characters from the Typography panel or the canvas menu, and ⌘-click (Ctrl-click) a link on the canvas, or click it in Preview, to open it.
- Crop and reframe images on the canvas: double-click an image layer, press Enter, or choose Crop image to drag crop handles over the still image, move the image behind the layer, or scale it from its corners, as many times as needed. Layers placed by auto layout, vectors, and layers with children keep their edges and can only be reframed.
- Generate images from a prompt into a new layer or into the image fill you are editing, with OpenAI or an OpenAI-compatible service and your own key, set up in Settings → Image services.
- Remove an image layer's background with your AI image service or remove.bg, or replace it with a scene you describe, from the canvas menu, the image fill picker, or the command palette; each change undoes in one step.
- Generate SVG from a prompt as editable layers with Recraft, fal.ai, or QuiverAI, using the vectorization service and key you already set up.
- Auto layout can distribute children with Space around, chosen from the gap menu in the properties panel: each child gets an equal share of the free space, half on each side, on top of the gap.
- Space around exports to CSS as `justify-content: space-around`, to Tailwind as `justify-around` and to design JSX as `justify="around"`, and HTML import reads it.
- `.fig` files keep Space around as plugin data, and Figma shows those frames as space between.
- Agents can call `get_style` for 21 curated style directions, each with a palette, font pairing, type scale, radii, spacing, elevation, and written guidance, in AI chat and over MCP.
- Agents can scale unlocked layers with their text, strokes, radii, effects, and spacing through the new `rescale` tool, as the Scale tool does.
- Agents can link text or a range of it to a web or mail address with the `hyperlink` option of `set_text_properties` and `set_font_range`.
- Agents can generate images, remove or replace image backgrounds, and generate editable SVG artwork with the user's own image service keys, through `generate_image`, `remove_background`, `replace_background`, and `generate_svg`.
- Replace a layer inside an instance with the copied layer (⌥⇧R, or Replace inside instance in the Edit and canvas menus); the replacement is kept as an override of the instance, stays when the component changes, and is saved in `.fig` files, including in instances of a component whose nested instance holds a replacement.
- Restore component layer, in the header of a replaced layer, brings the component's layer back.
- The instance header swaps any instance, nested instances included, to another component without an instance-swap property; components that would contain themselves are shown disabled.
- Pasting layers from another open document that use its variables or styles asks first whether to import them or paste the layers as they look.
- When the document already has a variable collection or style with the same name, each one can be set to use the existing one or add the copy under a new name; layers that use the existing one take its values.
- Import CSS custom properties as variables: `:root` and Tailwind `@theme` set each collection's defaults, while `[data-theme]`, class selectors and `:root` blocks inside `@media`, `@supports` or `@container` become modes with that condition and inherit the defaults they leave out.
- Link a CSS file to the document to pull its custom properties into variables and push variables back into the same file. Push keeps the file's comments, formatting, color notation and other rules, and removes nothing.
- Optionally pull a linked stylesheet whenever it changes, on desktop and in browsers that grant file access.
- The AI chat now comes with built-in skills: guides for landing pages, mobile apps, web apps, dashboards, slides, design systems, and Tailwind CSS v4, plus skills that fix layout, restyle a design, add dark mode, and review a design.
- A Pick a skill button in the chat composer starts a message with any skill you can run, built in or your own, and links to Settings › Skills.
- The chat composer offers the model, reasoning effort, and mode that Claude Code, Codex, and Gemini CLI advertise for their sessions; a choice applies to the running session at once and to later sessions with that agent, except modes that skip permission requests, which apply to one session only.
- Settings → AI → Ask before changes makes the built-in AI ask before each action that changes the document or uses an MCP server tool not marked read-only, with Allow, Always allow for the rest of the chat, and Deny.
- On desktop, each chat can give its coding agent a project folder to work in, chosen from the chat header and confirmed first; sessions there start in the agent's default mode, and only the chosen model and reasoning effort carry over.
- The chat header shows how full the model's context window is, in tokens, with a breakdown of input, cached input and output for the latest reply.
- A style kit (colours, fonts and direction, optionally merged from the document's own styles) and up to four reference images can be pinned to a chat conversation, and the AI follows them in every message of that conversation.
- "Let it cook" in the AI chat asks for two to six variants side by side as new frames, exploring layout or style. "Don't iterate" asks for one design in a single pass.
- Layers can carry Notes for AI: a context that agents respect when a message concerns the layer, and a prompt that Run prompt sends to the chat. Notes and prompt cards from .pen files are read the same way.
- The built-in AI chat with your own API key can use the external MCP servers you enable in Settings → MCP, alongside coding agents; while the chat asks before actions, it also asks before external tools that are not read-only.
- MCP connections can sign in with OAuth, so hosted servers such as Notion or Linear work without pasting a token; sign-ins are kept with your other credentials and refresh automatically.
- The desktop app can run local MCP servers from a command with arguments and environment variables. It asks in a system dialog before a command runs for the first time, including when a coding agent would start it.
- Test connection in an MCP connection's settings shows how many tools the server offers or why it could not connect.
- Amazon Bedrock is a model provider: choose a region and connect Claude with a Bedrock API key, or in the desktop app with AWS access keys.
- Google Vertex AI is a model provider: run Claude and Gemini in your Google Cloud project and location with an access token, or Gemini alone with an API key in express mode.
- The desktop app can add its MCP server to Claude Code, Claude Desktop, Codex, Gemini CLI, OpenCode, Kiro, Cursor, and VS Code with one switch each under Settings → MCP → Other apps. Switching it off removes the entry and leaves the rest of each config file unchanged, the original file is backed up before the first change, and the app refuses any write that would change anything other than its own entry.
- A Slides panel lists the page's top-level frames as numbered thumbnails in layer order: drag a slide or press Alt with an up or down arrow to reorder it, click it to show it on the canvas, and export every slide, in order, to one PDF or PowerPoint file.
- Present (Cmd/Ctrl+Enter, View › Present, or the top bar) shows the page's slides full screen one at a time: arrow keys, Space, Enter, Page Up/Down, and the scroll wheel step through them, Escape leaves and returns the canvas and keyboard focus to where they were, and a long page can be shown at 100% and scrolled.
- Cloud documents can be shared as a snapshot link: a view-only link to one saved version that you can update to the latest save or delete.
- People who open a Cloud link, snapshot, or public document can download it as a .fig file.
- Cloud links, invitations, and direct access support a "Can comment" role that lets people view, comment, reply, and resolve without editing; deleting comments and moving pins stay with editors.
- Cloud accounts can claim a public profile at /u/<handle> that lists the workspaces they make public, after confirming that anyone will be able to open and download every file in them.
- New designs are kept as drafts on this device as you work, so closing them asks nothing. Home lists them under Drafts with Open, Save As… and Delete draft, and drafts deleted in one window disappear from the others.
- Unsaved changes to an open file are kept as a backup. The next time that file opens, a Recovered changes dialog offers Save, Save As… or Don't Save. Saving the file drops older backups, and a backup whose file has not opened for a week is listed in Recover unsaved work.
- The desktop app and CLI open the `.pen` libraries a `.pen` document imports, so the library components and variables it uses look as they do in pen.dev and stay read-only. The desktop app reads libraries up to two folders above the document, never from the home folder or above it, and not through links; the CLI reads them inside the working directory.
- `.pen` script and browser nodes open as labelled placeholder frames that keep their script file, inputs, page address and view.
- Paste HTML copied from a web page onto the canvas as styled, editable layers; scripts, event handlers, frames and MathML in it are removed first.
- A Chrome extension (built from `extensions/chrome` and loaded unpacked) copies a whole page or a picked element with its computed styles and images, and Cmd/Ctrl+V pastes it as editable layers in one frame named after the page. You can pick the element with the keyboard alone.
- `@open-pencil/web-capture` defines the web capture format and provides a capturer for pages and Electron apps that copies a page or element for pasting into the canvas.
- Embed mode: a web page can show the editor in an iframe with `?embed&origin=<page origin>` and, after an origin-checked handshake, drive it over a MessagePort to load documents, read selection and pages, export images, and get the document back as `.fig`.
- Embedded documents are read-only unless the embed URL has `allow-edit` and the host page asks to edit; the host page is told about every change, and `chrome` keeps the toolbar and panels.
- Shader Mode shows a shader fill large on its own, with play and pause, a phase scrubber, and the shader's settings beside it; open it from the shader fill picker.
