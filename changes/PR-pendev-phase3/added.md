- Exports deterministic, human-readable `.pen` documents from scene graphs through the Core and CLI conversion APIs.
- Runs a design agent headlessly from the CLI against any [OI]-compatible model, confining its file output to `--root` and withholding `eval` and network tools unless `--allow` names them.
- Runs several named agents over one document with `--agents`, where each agent's role can only narrow the run's tools and never grant one it withheld.
- Adds a Prototype section to the properties panel, where a layer takes click or after-delay interactions that navigate to a frame, open or close an overlay, or go back, with instant or dissolve transitions, all stored as Figma prototype reactions.
- Reads and writes Figma prototype reactions in `.fig` files, so interactions survive a round trip and keep reaction ids as the file's GUIDs.
- Draws a selected layer's prototype connections on the canvas as dashed arrows to the frames each reaction shows.
- Plays a prototype from the Prototype section: clicks follow their interactions between frames, overlays open over the frame and close, after-delay interactions run on their own, dissolve transitions crossfade, and Escape returns to editing.
- Adds a built-in browser to the desktop app: a separate window that opens `http` and `https` pages with back, forward, reload, zoom, and device-size presets, imports the whole page or one picked element as layers, and places a screenshot of the view, the full page, or one element on the canvas; the page gets no access to the app, and MCP tools can load a page, read an element, and send a screenshot to the canvas while that window is open.
- Lets the chat work on the page in that browser: it reads one element or a short outline of the page, marks an element as a chip that outlines it in the window while the pointer is over the chip, clicks, types, presses a key, scrolls, or waits for the page to change, opens another `http` or `https` address, and places a screenshot of the view or the page on the canvas, with each change, screenshot, and new address allowed for that site when Settings asks before changes.
- Reads the open page, keeps a web citation on a sticky, and cites that page on a board. Web search is not included.
- Settings lists installed plugins and the capabilities each one was granted. Saving a manifest does not run it. Plugins do not run yet.
