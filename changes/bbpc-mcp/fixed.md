- An MCP tool call that fails now reports an error to the client, instead of an error message delivered as a successful result.
- A headless `tool call` that fails exits with an error and leaves the document file unchanged.
- `switch_page` and `viewport_set` move the editor, so the page and view a tool sets are the page and view the next call reads.
- A color a tool does not understand, such as a mistyped hex value, is refused instead of painting the layer black.
- `get_node` reports the padding and alignment of an auto layout frame.
- Saving text that truncates keeps it in a fixed box that ends its lines.
- `batch_update` takes the list of operations its schema describes.
- `export_image` accepts its formats in either letter case.
- `insert_icon` places the icon at the x and y it is given.
- The canvas draws the selection again after the browser takes its WebGL context away.
- A page exported as standalone HTML keeps its fonts when images and fonts are saved beside the page.
- An MCP client that reconnects without closing its old session takes that session's slot back instead of being refused.
- An MCP session left idle for two minutes gives its slot to the next client, and a session another client is using is never taken.
- A client refused for lack of a session slot is told the server's limit and how long an idle session holds its slot.
- The app starts its MCP server again after the server stops, instead of staying unreachable until the app restarts.
- An MCP server that keeps stopping is reported after repeated attempts, instead of being started again forever.
