- Mermaid flowcharts whose labels nest HTML tags very deeply now import instead of failing.
- draw.io SVG exports whose embedded diagram is percent-encoded or Base64 now open as draw.io files.

- Zoom to selection, ruler selection marks, and Align measure rotated layers by their visible corners, and the bounds of rotated underlined text follow the rotation.
- The Scale tool scales text on a path together with its layer.
- Snapping measures a rotated line from its start point, where it is drawn, and no longer draws a guide for an equally near edge it did not snap to.
- Layers with a corrupt parent cycle no longer freeze the editor.
- A `.fig` file with a component property pointing to a missing parent property now opens instead of failing to load.
- A duplicated layer inside an instance no longer keeps stale styles after its component changes.

- A `.fig` file with a nested color expression now opens with the variable kept unsupported instead of failing.

- Changing a setting keeps preferences that a newer version of Pairdraw saved.

- Creating a variable from the Opacity field keeps the layer's opacity instead of setting it to 100%.
- Aligning rotated layers lines up their visible edges instead of shifting them off the target.

- Line height and letter spacing bound to a variable keep the unit they are set in, so a 120% line height stays a percentage of the font size instead of becoming 120 px.

- Aligning a single rotated layer uses its drawn edge, so it lines up with its parent the way a group of layers does.
