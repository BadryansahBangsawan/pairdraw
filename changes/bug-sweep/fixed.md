- Creating a variable from a property field binds it to every selected layer and corner the field edits, not only the first.
- Opening a `.pen` file with a number too large to store now reports where it is, instead of opening and then saving a file that can't be reopened.
- Undoing Move to page selects the moved layers again.
- Zooming to fit very large content stops at the 2% minimum zoom.
- A streamed render preview loads its fonts again after a failed load instead of drawing without them until the call ends.
- Saving a `.pen` file keeps each layer's `metadata` instead of dropping it.
- Opening a `.pen` file that repeats a layer ID keeps every layer instead of losing one or detaching its children.
- A `.pen` gradient of an unknown type opens as a linear gradient instead of disappearing.
- In `.pen` files, text such as `no` or `0` in a true/false field reads as the field's default instead of turning it on.
- AI setup no longer prefixes omp's Bun install command with sudo when npm's global folder needs administrator rights.
- Saving by download in a browser without file access keeps the draft and recovery copy, so cancelling the download no longer loses the work.
- Importing HTML names layers after their `data-name`, so a page exported to HTML and imported back keeps its layer names.
