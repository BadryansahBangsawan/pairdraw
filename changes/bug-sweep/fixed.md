- Creating a variable from a property field binds it to every selected layer and corner the field edits, not only the first.
- Opening a `.pen` file with a number too large to store now reports where it is, instead of opening and then saving a file that can't be reopened.
- Undoing Move to page selects the moved layers again.
- Zooming to fit very large content stops at the 2% minimum zoom.
- A streamed render preview loads its fonts again after a failed load instead of drawing without them until the call ends.
- Saving a `.pen` file keeps each layer's `metadata` instead of dropping it.
- Opening a `.pen` file that repeats a layer ID keeps every layer instead of losing one or detaching its children.
- A `.pen` gradient of an unknown type opens as a linear gradient instead of disappearing.
- In `.pen` files, text such as `no` or `0` in a true/false field reads as the field's default instead of turning it on.
- AI setup no longer prefixes omp's Bun install command with sudo when npm's global folder needs administrator rights.
- Saving by download in a browser without file access keeps the draft and recovery copy, so cancelling the download no longer loses the work.
- Importing HTML names layers after their `data-name`, so a page exported to HTML and imported back keeps its layer names.
- Imported HTML resolves CSS custom properties declared on any selector, uses `var()` fallbacks, inherits text styles set on `:root`, and resolves `calc()` products written with the number first.
- JSX style strings keep semicolons inside `url()` and quoted values, so data URLs import intact.
- Damaged `.fig` files and Figma clipboard data fail with an error instead of freezing the app or loading wrong values, and text with an unpaired surrogate no longer loses the character after it when saved.
- A raw `.fig` file that is cut short reports a corrupted file instead of a range error.
- `parseVarint` from `@pairdraw/kiwi/fig` reads values of 2³¹ and above correctly.
- Text whose characters bind a size or spacing to a variable keeps its scaled size after the Scale tool, and a bound font weight no longer changes with the scale.
- Connectors brought back when a failed edit is rolled back keep following their layers.
- Mermaid flowcharts whose labels nest HTML tags very deeply now import instead of failing.
- draw.io SVG exports whose embedded diagram is percent-encoded or Base64 now open as draw.io files.
- The streaming Design JSX preview now shows Reka parts such as `Switch.Root` while the JSX is still arriving.
- Zoom to selection, ruler selection marks, and Align measure rotated layers by their visible corners, and the bounds of rotated underlined text follow the rotation.
- The Scale tool scales text on a path together with its layer.
- Snapping measures a rotated line from its start point, where it is drawn, and no longer draws a guide for an equally near edge it did not snap to.
- Layers with a corrupt parent cycle no longer freeze the editor.
