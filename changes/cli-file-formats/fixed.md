- `pairdraw export --format pdf` writes the PDF when the CLI runs under Node, not only under Bun.
- Converting to draw.io says which variables the file cannot hold, instead of dropping them silently.
- Opening a file whose `.fig` archive is damaged or is not a ZIP fails with a clear error instead of decoding different content silently.
- Converting to draw.io and back keeps a frame a frame, a rectangle a rectangle, and every layer name.
- A `.pen` roundtrip keeps the page name instead of replacing it with the first layer's.
- Printing tokens says which variable took a numbered custom property name because another token's name collides with it.
- `pairdraw variables` counts the variables its filters leave, not the whole document.
- `pairdraw variables --json` writes JSON for a document without variables instead of a sentence.
- `pairdraw lint` refuses an unknown preset or rule with a clear error instead of crashing or passing silently.
- `pairdraw export --thumbnail` writes a page thumbnail fitted to `--width` and `--height` for PNG, JPG, and WEBP, instead of always failing.
- `export --quality`, `export --scale`, `export --width`, `export --height`, and `analyze colors --threshold` refuse a value outside their range instead of using it.
- Every command refuses an extra positional argument, instead of ignoring it or taking it for the output path.
