- `get_css` reads a node subtree as compact CSS-like lines — `flex:row;gap:12px;padding:16px 24px;bg:var(--color/brand, #4F46E5);radius:8px`, text as `font:600 14px/20px Inter` — with lengths in px and a `max_bytes` budget, so an agent reads only what a task needs: on the same five agent tasks it costs 44.6% fewer bytes than `get_jsx` and 78.5% fewer than `describe`/`get_node`, measured through the tools.
- `set_layout` takes `padding` and `gap` as CSS shorthand (`"16px 24px"`, `"12px 4px"`), `set_radius` takes `"12px 12px 4px 0"`, and `set_fill` takes a token name (`"var(--color/brand)"`), painting its value and binding the fill; a name two variables share is refused with both, never guessed.
