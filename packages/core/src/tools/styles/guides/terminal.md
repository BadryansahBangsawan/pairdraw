## Layout

- A page that reads like a terminal session: a narrow column, prompts (`$`, `>`) before headings, and blocks separated by ASCII rules or box-drawing borders.

## Typography

- Monospace for everything; headings in bold, prefixed with symbols or comments (`#`, `//`). Body 14–16 px with line height 1.6.

## Color

- Black-green background, pale phosphor text, bright green for commands, links, and actions, and amber for warnings and highlights.

## Shape and depth

- No or tiny radii; 1 px borders; no shadows. A blinking cursor block or a subtle scanline texture is the only ornament.

## Imagery and icons

- Code blocks, command output, ASCII art, and simple diagrams; avoid photography. Icons as text glyphs.

## Components

- Copyable command blocks, key–value tables, tabs styled as file names, and buttons styled as `[ run ]`.

## Avoid

- Proportional fonts, rounded cards, gradients, and stock photos.
