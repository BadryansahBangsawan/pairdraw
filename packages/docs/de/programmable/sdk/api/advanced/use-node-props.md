# useNodeProps

`useNodeProps()` ist das Hilfsmittel auf niedriger Ebene hinter übergeordneten Composables wie `useAppearance`, `useLayout` und `useTypography`.

Verwenden Sie es, wenn ein eigenes Panel gemischte Werte erkennen, eine Eigenschaft mehrerer ausgewählter Objekte ändern, Array-Einträge bearbeiten oder Eigenschaften mit Rückgängig-Unterstützung speichern muss.
