# useToolbarState

`useToolbarState()` gibt den Blätterzustand der Werkzeugkategorien auf Mobilgeräten sowie Hilfsfunktionen wie `goPrev()` und `goNext()` für responsive Werkzeugleisten zurück.

Verwenden Sie das Composable, wenn Sie Werkzeugleisten-Layouts auf Grundlage von `ToolbarRoot` aufbauen.
