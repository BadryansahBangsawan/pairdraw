# CanvasSurface

`CanvasSurface` rendert das eigentliche `<canvas>`-Element, das der Arbeitsflächen-Stack des SDK verwendet.

Innerhalb von `CanvasRoot` verwaltet das SDK die Referenzen auf das Canvas und die Anbindung an den Renderer, während die Anwendung Anordnung und Gestaltung bestimmt.
