## Empfohlener Weg

- Beginnen Sie mit den **Komponenten**, wenn Sie wiederverwendbare Bausteine für Editoroberflächen erstellen.
- Beginnen Sie mit den **Composables**, wenn Sie Editorzustand und Aktionen anbinden.
- Verwenden Sie die **Erweiterte API** nur, wenn Sie Hilfsmittel auf niedriger Ebene oder Komponentenkontexte benötigen.
