# useLayerDrag

`useLayerDrag(editor, indentPerLevel?)` conecta el comportamiento de pragmatic-drag-and-drop con las filas del árbol de capas y traduce las instrucciones de soltar a operaciones de reordenación del editor.

Úselo al ampliar o sustituir la interfaz de arrastre predeterminada del árbol de capas.
