# usePropScrub

`usePropScrub(editor)` coordina las actualizaciones de propiedades en directo mientras se arrastra para ajustar un valor y confirma los cambios, teniendo en cuenta deshacer, cuando termina la interacción.

Úselo al crear controles numéricos que ajusten directamente las propiedades de los objetos seleccionados.
