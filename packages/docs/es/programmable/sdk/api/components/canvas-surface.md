# CanvasSurface

`CanvasSurface` representa el elemento `<canvas>` real que usa la pila de lienzo del SDK.

Úsela dentro de `CanvasRoot` cuando quiera las refs del lienzo y la integración con el renderizado gestionadas por el SDK, pero con la disposición y los estilos a cargo de la aplicación.
