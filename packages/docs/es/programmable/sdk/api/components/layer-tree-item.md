# LayerTreeItem

`LayerTreeItem` representa una fila del árbol de capas y expone, mediante su ranura predeterminada, controladores para la selección, el despliegue, la visibilidad, el bloqueo y el cambio de nombre.

Úselo cuando quiera un marcado de fila propio de la aplicación con el comportamiento del árbol de capas que proporciona el SDK.
