# LayerTreeRoot

`LayerTreeRoot` es la primitiva del SDK para representar un árbol de capas con marcado y estilos propios de la aplicación.

Úsela cuando quiera una estructura de árbol reutilizable y la conexión de las interacciones sin una presentación integrada. Combine el componente con `LayerTreeItem` o represente las filas con una ranura propia.
