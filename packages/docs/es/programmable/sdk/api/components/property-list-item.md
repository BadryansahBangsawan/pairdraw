# PropertyListItem

`PropertyListItem` expone controladores para actualizar, aplicar cambios parciales, eliminar y cambiar la visibilidad de un elemento de la matriz dentro de `PropertyListRoot`.

Úselo para crear interfaces de fila propias para rellenos, contornos o efectos. La aplicación decide cómo representar la miniatura, los controles y el menú de cada fila.
