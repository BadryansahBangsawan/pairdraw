# ToolbarRoot

`ToolbarRoot` es la primitiva de barra de herramientas sin estilos de `@pairdraw/vue`.

Úsela cuando quiera una estructura y un contexto de barra de herramientas reutilizables con sus propios botones, estilos y disposición.
