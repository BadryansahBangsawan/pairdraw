# Guía de usuario

Pairdraw es un editor de diseño de código abierto y compatible con Figma: totalmente local, con AI integrada y programable. Esta guía cubre todo lo que necesitas saber para usar el editor con soltura.

::: tip Atajos en todas las plataformas
En esta guía los atajos de teclado usan la notación de Mac: <kbd>⌘</kbd> = <kbd>Command</kbd> (<kbd>Ctrl</kbd> en Windows/Linux), <kbd>⌥</kbd> = <kbd>Option</kbd> (<kbd>Alt</kbd>), <kbd>⇧</kbd> = <kbd>Shift</kbd>.
:::
