# toolCursor

`toolCursor(tool, override?)` associe un outil de l’éditeur au curseur que le SDK doit utiliser, tout en permettant de le remplacer explicitement avec `override`.

Utilisez cette fonction pour garder un comportement de curseur cohérent dans une zone de travail ou une interface d’outils personnalisée.
