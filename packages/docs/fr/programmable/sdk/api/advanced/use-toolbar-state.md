# useToolbarState

`useToolbarState()` renvoie l’état de pagination des catégories sur mobile et des fonctions comme `goPrev()` et `goNext()` pour les barres d’outils adaptatives.

Utilisez-le pour construire la mise en page d’une barre d’outils au-dessus de `ToolbarRoot`.
