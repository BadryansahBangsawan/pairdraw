# CanvasRoot

`CanvasRoot` est le composant structurel de zone de travail de `@pairdraw/vue`.

Utilisez-le pour obtenir la structure et le contexte de zone de travail fournis par le SDK, avec une disposition et des styles propres à l’application. Placez [CanvasSurface](./canvas-surface) à l’intérieur ou accédez au contexte avec [useCanvasContext](../advanced/use-canvas-context).
