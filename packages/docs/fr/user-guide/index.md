# Guide d’utilisation

Pairdraw est un éditeur de design open source, compatible avec Figma, entièrement local, doté d’une IA intégrée et programmable. Ce guide couvre tout ce qu’il faut savoir pour utiliser l’éditeur efficacement.

::: tip Raccourcis multiplateformes
Dans ce guide, les raccourcis clavier utilisent la notation Mac : <kbd>⌘</kbd> = <kbd>Command</kbd> (<kbd>Ctrl</kbd> sous Windows/Linux), <kbd>⌥</kbd> = <kbd>Option</kbd> (<kbd>Alt</kbd>), <kbd>⇧</kbd> = <kbd>Shift</kbd>.
:::
