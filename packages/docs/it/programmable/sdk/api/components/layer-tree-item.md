# LayerTreeItem

`LayerTreeItem` disegna una riga dell'albero dei livelli ed espone nel proprio slot predefinito i gestori per selezione, espansione, visibilità, blocco e rinomina.

Usalo quando vuoi il markup delle righe deciso dall'applicazione insieme al comportamento dell'albero dei livelli fornito dall'SDK.
