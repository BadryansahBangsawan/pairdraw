# PropertyListItem

`PropertyListItem` espone i gestori di aggiornamento, modifica parziale, rimozione e visibilità per un elemento dell'array all'interno di `PropertyListRoot`.

Usalo per costruire righe personalizzate negli elenchi di riempimenti, contorni o effetti.
