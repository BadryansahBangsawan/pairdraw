# ToolbarItem

`ToolbarItem` espone lo stato attivo e il comportamento di selezione di uno strumento della barra.

Usalo dentro `ToolbarRoot` quando vuoi un markup personalizzato per il pulsante ma lo stesso collegamento per la scelta dello strumento.
