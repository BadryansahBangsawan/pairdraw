# ToolbarRoot

`ToolbarRoot` è il componente senza stile di `@pairdraw/vue` per la barra degli strumenti.

Usalo quando vuoi una struttura e un contesto riutilizzabili per la barra, con pulsanti, stili e disposizione tuoi.
