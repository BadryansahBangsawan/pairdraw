# Guida utente

Pairdraw è un editor di design open source compatibile con Figma: completamente locale, con AI integrata e programmabile. Questa guida spiega tutto ciò che serve per usare l’editor in modo efficace.

::: tip Scorciatoie su tutte le piattaforme
In tutta la guida le scorciatoie da tastiera usano la notazione Mac: <kbd>⌘</kbd> = <kbd>Command</kbd> (<kbd>Ctrl</kbd> su Windows/Linux), <kbd>⌥</kbd> = <kbd>Option</kbd> (<kbd>Alt</kbd>), <kbd>⇧</kbd> = <kbd>Shift</kbd>.
:::

- [Navigazione nell’area di lavoro](./canvas-navigation) — spostare la vista, usare lo zoom e lo strumento Mano;
