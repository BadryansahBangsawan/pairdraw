# Рендерер JSX

JSX для дизайна в Pairdraw создаёт объекты сцены, а не DOM браузера. Для построения редактируемого дизайна можно использовать читаемые деревья компонентов, выражения JavaScript и переиспользуемые функции.

## Создание дизайна

Инструмент `render` принимает строки JSX в чате с ИИ и MCP. В коде приложения или библиотеки без интерфейса импортируйте `Frame`, `Text` и другие элементы для описания дизайна из `@pairdraw/design-jsx`, а объекты создавайте через `renderTree` или `renderJSX` из `@pairdraw/core/design-jsx`: они добавляют значки, преобразование SVG и компоновку. Чтобы писать такие деревья в TSX, укажите в `tsconfig.json` `"jsxImportSource": "@pairdraw/design-jsx"` вместе с `"jsx": "react-jsx"` или добавьте в файл комментарий `/** @jsxImportSource @pairdraw/design-jsx */`. Какие API доступны в `eval`, определяет среда сценариев; экспорты пакета не становятся там глобальными автоматически.

[Общий справочник по описанию дизайна](/reference/design-authoring) содержит исполняемые примеры, рекомендации по компоновке и перечень поддерживаемого синтаксиса. Он создаётся из того же источника, который используют чат, ACP, промпты генерации кода и устанавливаемый навык для агентов.

## Элементы

Используйте фреймы и текст для композиции, фигуры для графики, а настоящие компоненты и экземпляры — для переиспользуемого содержимого редактора. Сама по себе функция JavaScript не создаёт компонент. См. [перечень элементов](/reference/design-authoring#supported-syntax-inventory).

## Свойства оформления

Для размеров по содержимому используйте Hug/Fill и flex или grid. Привязывайте семантические переменные вместо копирования значений. См. разделы [композиция и компоновка](/reference/design-authoring#composition-and-layout), [заливка и текст](/reference/design-authoring#paint-text-and-artwork) и [переменные и компоненты](/reference/design-authoring#variables-and-components).

## Экспорт в JSX

```sh
pairdraw export design.fig -f jsx                   # Формат Pairdraw
pairdraw export design.fig -f jsx --style tailwind  # Классы Tailwind
```

Экспортированный JSX Pairdraw можно изменить и снова отрисовать в документе. Экспорт записывает скрытые и заблокированные слои, ограничения, пределы размеров, многослойные, градиентные заливки и заливки изображениями, обводки, эффекты, маски и привязки переменных, поэтому при отрисовке экспорта они воспроизводятся, а `diff_jsx` показывает изменения любого из них. Форматированный текст со смешанными стилями, векторные контуры, сетки компоновки, общие стили и определения свойств компонентов пока не записываются. Экземпляры записываются как фреймы со своим содержимым, поэтому экспортированный JSX самодостаточен. См. [экспорт из CLI](./cli/exporting).

## Визуальное сравнение

JSX позволяет проверять структурные изменения дизайна как код. Используйте `get_jsx` и `diff_jsx`, чтобы посмотреть изменения, а затем проверьте фактический результат отрисовки: чистое структурное сравнение не доказывает визуального совпадения.
