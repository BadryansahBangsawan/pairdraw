# Автоматическая компоновка

Автоматическая компоновка размещает дочерние объекты внутри фрейма. Доступны два режима: **Flex** с горизонтальным или вертикальным потоком и **Grid** со строками, столбцами и настраиваемыми дорожками.

## Включение

- Выделите фрейм и нажмите <kbd>⇧</kbd><kbd>A</kbd> (<kbd>Shift</kbd> + <kbd>A</kbd>), чтобы включить или отключить автоматическую компоновку.
- Выделите отдельные объекты (без родительского фрейма) и нажмите <kbd>⇧</kbd><kbd>A</kbd>, чтобы поместить их в новый фрейм с автоматической компоновкой.

При создании фрейма Pairdraw сначала сортирует объекты по их видимому положению: слева направо для горизонтальной компоновки и сверху вниз для вертикальной.

## Направление

Выберите, как располагаются дочерние объекты:

- **Горизонтальное:** объекты располагаются слева направо.
- **Вертикальное:** объекты располагаются сверху вниз.
- **Перенос:** при нехватке места объекты переходят на следующую строку или в следующий столбец.

## Расстояния

### Интервал

Интервал определяет расстояние между соседними дочерними объектами. Одно значение действует между всеми дочерними объектами.

### Внутренние отступы

Внутренние отступы задают расстояние между границей фрейма и его содержимым. Можно использовать одно общее значение или раскрыть настройки и задать каждую сторону отдельно (сверху, справа, снизу, слева).

## Выравнивание

### Основная ось

Определяет, как дочерние объекты распределяются вдоль направления компоновки:

- **Начало:** объекты располагаются у начала оси.
- **Центр:** объекты выравниваются по центру.
- **Конец:** объекты располагаются у конца оси.
- **Распределить:** свободное место равномерно распределяется между объектами.
- **Отступ вокруг:** каждый объект получает равную долю свободного места, по половине с каждой стороны, сверх интервала. Режим выбирается в меню поля интервала.

### Поперечная ось

Определяет положение дочерних объектов перпендикулярно направлению компоновки:

- **Начало:** выравнивание по началу поперечной оси.
- **Центр:** выравнивание по центру.
- **Конец:** выравнивание по концу оси.
- **Растянуть:** дочерние объекты занимают всю поперечную ось.

## Размер дочерних объектов

У каждого дочернего объекта во фрейме с автоматической компоновкой может быть свой режим размера:

- **Фиксированный:** использовать явно заданную ширину или высоту.
- **Заполнить:** растянуться на доступное место в родителе.
- **По содержимому:** подобрать размер по содержимому.

Первое фактическое изменение ширины или высоты переводит только эту ось из режима «Заполнить» или «По содержимому» в фиксированный режим. Простое получение фокуса полем не меняет режим размера.

## Учёт обводки в раскладке

По умолчанию фрейм с автоматической компоновкой размещает содержимое так, будто ни у одного слоя нет обводки, — как в Figma. Включите **Учитывать обводку в раскладке** в разделе «Раскладка», чтобы оставить место для обводок: собственная обводка фрейма сдвигает содержимое внутрь, а внешние обводки дочерних объектов занимают место между ними.

## Изменение порядка

Перетащите дочерний объект внутри фрейма, чтобы изменить его место среди соседних. Индикатор вставки покажет, куда попадёт объект. Объект, перетащенный во фрейм с автоматической компоновкой извне, вставляется так же; во фрейме с переносом он попадает в строку под указателем. Объект, нарисованный внутри фрейма с автоматической компоновкой, добавляется в конец его потока.

Удерживайте <kbd>⌃</kbd> (<kbd>Ctrl</kbd> в Windows и Linux) при перетаскивании, чтобы не учитывать автоматическую компоновку: объект окажется там, где вы его отпустили, как дочерний объект с абсолютным положением.

## Панель свойств

Когда выделен фрейм с автоматической компоновкой, раздел «Раскладка» на панели свойств показывает все её настройки: направление, интервал, отступы, распределение по основной оси и выравнивание по поперечной.

## CSS Grid

Grid размещает дочерние объекты в строках и столбцах с явно заданными размерами дорожек.

### Включение Grid

Выделите фрейм с автоматической компоновкой и нажмите значок сетки на панели раскладки, чтобы переключить режим Flex на Grid.

### Размеры дорожек

Дорожки столбцов и строк задаются в трёх режимах:

- **fr:** пропорциональная доля доступного места.
- **px:** фиксированный размер в пикселях.
- **auto:** размер по содержимому.

Например, `1fr 200px 1fr` создаёт три столбца: фиксированный центральный и два гибких боковых.

### Интервалы строк и столбцов

Горизонтальное (между столбцами) и вертикальное (между строками) расстояние между ячейками настраивается отдельно.

### Размещение объектов

По умолчанию объекты последовательно заполняют свободные ячейки по строкам. В свойствах дочернего объекта можно задать начальную строку и столбец, а также количество занимаемых ячеек.

### Экспорт в JSX и Tailwind

Grid экспортируется в JSX с классами Tailwind, например `grid grid-cols-3`, `gap-x-4 gap-y-2` и `col-start-2 row-span-2`.

## Советы

- Автоматическая компоновка пересчитывается сразу после создания, поэтому границы выделения обновляются немедленно.
- Вкладывайте фреймы с автоматической компоновкой друг в друга для сложных адаптивных интерфейсов (например, вертикальный фрейм с горизонтальными строками).
- Режим «Заполнить» заставляет дочерний объект занять оставшееся место, как `flex-grow: 1` в CSS.
- Grid подходит для панелей мониторинга, галерей, форм и других двумерных структур.
- Создание фреймов, к которым применяется автоматическая компоновка, описано в разделе [Фигуры](./drawing-shapes).
