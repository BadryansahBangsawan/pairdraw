# Компоненты

Компонент — это переиспользуемый элемент дизайна. После изменения основного компонента все связанные экземпляры обновляются автоматически.

## Просмотр компонентов

Откройте вкладку **Ассеты** на левой панели, чтобы увидеть локальные компоненты и подключённые библиотеки. Доступны представление сеткой и списком и поиск по имени компонента; выберите компонент, чтобы увидеть подробности. Добавить ассет на холст можно щелчком, клавишей <kbd>Enter</kbd> или перетаскиванием.

Локальные ассеты сгруппированы по исходным страницам. Ассеты опубликованной библиотеки остаются доступны, если соответствующая редакция уже загружена, в том числе когда удалённый поставщик временно недоступен.

## Создание компонента

Выделите фрейм или группу и нажмите <kbd>⌥</kbd><kbd>⌘</kbd><kbd>K</kbd> (<kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>K</kbd>). Выделение станет переиспользуемым компонентом.

Любой другой слой или несколько слоёв Pairdraw помещает в новый белый компонент по их общей ограничивающей рамке, на место самого верхнего слоя в списке слоёв; если слой один, компонент получает его имя.

Над компонентом отображается фиолетовая подпись со значком ромба.

## Наборы компонентов и варианты

Выделите не менее двух компонентов и выберите **Создать набор компонентов** в контекстном меню, чтобы объединить их в набор компонентов — контейнер с пунктирной фиолетовой рамкой и внутренним отступом 20 пикселей вокруг дочерних объектов, как в Figma. Наборы, созданные скриптами через `figma.combineAsVariants()`, облегают компоненты вплотную, как это делает API плагинов Figma.

Каждый компонент в наборе может задавать значения нескольких параметров варианта, например `Size=Small`, `State=Hover` и `Theme=Dark`. Pairdraw поддерживает неполные сочетания, поэтому создавать все возможные сочетания необязательно. Верхний левый вариант используется по умолчанию и служит заменой, если после обновления точного сочетания больше нет.

Выделите компонент и нажмите **Добавить вариант** в заголовке панели, чтобы превратить его в набор компонентов, как в Figma: компонент становится `Property 1=Default`, а под ним появляется копия с именем `Property 1=Variant2`. В наборе **Добавить вариант** копирует последний вариант со следующим значением. Свойства вариантов набора — это строки его списка **Свойства**; щёлкните строку, чтобы переименовать свойство либо добавить, переименовать, перетаскиванием переставить или удалить его значения. Если удалить значение, которое используют варианты, они сначала переходят на другое значение, а варианты с полностью совпадающими значениями перечисляются в уведомлении, которое их выделяет.

## Свойства компонентов

Компоненты и наборы компонентов поддерживают переиспользуемые свойства: текст, логическую видимость, замену экземпляра и слот. Выделите экземпляр, чтобы менять их значения без отвязки. Свойства и их значения сохраняются при записи и повторном открытии файлов `.fig`.

Чтобы связать слой основного компонента со свойством, нажмите кнопку связи там, где находится его поле: **Типографика** для текста, **Внешний вид** для видимости и заголовок экземпляра для заменяемого компонента. Создайте свойство из текущего значения слоя или выберите существующее; после этого поле показывает свойство вместо значения. Ввод в связанный текст задаёт свойство — его значение по умолчанию в основном компоненте и значение экземпляра в экземпляре.

Выделите основной компонент, чтобы увидеть его **Свойства**. Щёлкните свойство, чтобы переименовать его, изменить значение по умолчанию, увидеть и отвязать управляемые им слои или удалить его; свойства можно переставлять перетаскиванием. **+** добавляет свойство текста, логическое свойство или свойство замены экземпляра.

Чтобы показать свойства вложенного экземпляра в экземплярах компонента, выберите **+ → Вложенные экземпляры** и отметьте его — как Expose properties from nested instances в Figma. Тогда экземпляры компонента перечисляют его свойства под его именем. Показать можно только экземпляр, у компонента которого есть свойства.

## Слоты

Слот — это фрейм основного компонента, содержимое которого каждый экземпляр может менять. Выделите фрейм внутри основного компонента и выберите **Создать слот** в контекстном меню или в разделе **Слоты** либо выделите другие слои, чтобы поместить их в новый фрейм-слот. В настройках слота задаются описание, предпочтительные компоненты и число элементов; экземпляр, выходящий за эти пределы, показывает предупреждение. В экземпляре можно добавлять, переставлять и удалять элементы слота или вернуть содержимое компонента.

## Поведение и предпросмотр {#behaviours-and-preview}

Поведение заставляет основной компонент или набор компонентов работать как настоящий элемент управления по образцу примитивов [Reka UI](https://reka-ui.com): Кнопка, Текстовое поле, Многострочное поле, Числовое поле, Переключатель-кнопка, Переключатель, Флажок, Радиокнопка, Группа радиокнопок, Группа переключателей, Ползунок, Прогресс, Вкладки, Раскрывающийся блок или Аккордеон. Выделите компонент и выберите поведение кнопкой **+** в разделе **Поведение**.

Раздел перечисляет, что нужно элементу управления:

- **Значения** — свойство, которое хранит каждое значение: свойство варианта или логическое свойство для состояний «Вкл.», «Отмечен», «Нажата», «Открыт», «Заполнено» или «Отключено» (с значениями варианта, означающими включено и выключено), текстовое свойство для текста поля или собственные минимум, максимум, шаг и значение по умолчанию ползунка.
- **Части** — слот, который рисует каждую часть, например бегунок переключателя, дорожку, диапазон и бегунок ползунка или список вкладок. Слот элементов группы содержит экземпляры её радиокнопок, переключателей или раскрывающихся блоков.
- **Состояния** — свойство варианта, значения которого рисуют состояния по умолчанию, при наведении, нажатии, фокусе и отключении. Значения с такими названиями сопоставляются автоматически.

Обязательные для элемента управления строки идут первыми, остальные — в **Ещё параметры**. Если в компоненте ещё нечего связать, строка предлагает это создать: текстовый слой и текстовое свойство, варианты Off и On или слот, а **Состояния** предлагает **Добавить варианты состояний**, что добавляет варианты компонента Default, Hover, Pressed, Focus и Disabled. Одиночный основной компонент, получивший так варианты, становится набором компонентов, а слот, добавленный в набор, появляется во всех вариантах. Пока элемент управления не работает, строка под его названием сообщает, чего ещё не хватает; щелчок по ней переходит туда.

Нажмите <kbd>⌥</kbd><kbd>⌘</kbd><kbd>↩</kbd> (<kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Enter</kbd>), выберите **Вид → Просмотр** или нажмите кнопку ▶ на верхней панели, чтобы просмотреть холст. Каждый слой верхнего уровня с элементами управления работает как живые компоненты Reka UI поверх холста, нарисованные вариантами компонента: переключатели переключаются, ползунки перетаскиваются, вкладки и аккордеоны открываются, а текстовые поля — настоящие поля ввода с курсором, выделением и вставкой браузера. Просмотр никогда не меняет документ и его историю. **Сбросить** возвращает все элементы управления в исходное состояние, а <kbd>Esc</kbd> или кнопка закрытия на плашке возвращает к редактированию. В разделённом виде каждый холст просматривается отдельно.

Поведения сохраняются в файлах `.fig` и публикуются вместе с компонентами библиотеки.

## Библиотеки компонентов {#component-libraries}

Библиотека публикует компоненты как неизменяемые редакции. У каждого опубликованного ассета есть постоянные идентификаторы библиотеки, ассета и редакции. Поэтому разные экземпляры могут оставаться на разных редакциях до явного обновления.

**Pairdraw Basics** — встроенный оригинальный набор: компоненты кнопки, поля, значка, карточки и аватара, опубликованные как `pairdraw-basics`. Он есть в панели ассетов без каталога: включите его там, чтобы вставлять компоненты, в том числе офлайн, и он остаётся после перезагрузки. `pairdraw libraries seed --root ./catalog` по-прежнему публикует тот же набор в файловый каталог.

### Публикация

1. Создайте компоненты и наборы компонентов, которыми хотите поделиться.
2. Откройте **Ассеты** и выберите **Управление библиотеками**.
3. Выберите **Опубликовать библиотеку**.
4. Укажите постоянный идентификатор библиотеки и отображаемое имя. После первой публикации идентификатор изменить нельзя.
5. При необходимости найдите нужные изменения и добавьте описание редакции.
6. Отметьте добавленные, изменённые, переименованные или удалённые ассеты, которые нужно включить.
7. Проверьте место публикации и нажмите **Опубликовать библиотеку**.

При следующих публикациях неотмеченные изменения останутся в ожидании. Неизменённые ассеты сохранят прежние определения. Удалённые определения останутся доступны, пока документы ссылаются на их исторические редакции.

### Подключение и вставка ассетов

Откройте **Ассеты → Управление библиотеками** и включите опубликованную библиотеку. Её компоненты появятся на панели ассетов рядом с локальными. Добавьте компонент щелчком, с клавиатуры или перетаскиванием на холст.

Опубликованные определения доступны в использующем документе только для чтения. Чтобы изменить определение, отредактируйте исходный документ и опубликуйте новую редакцию. Связанные экземпляры по-прежнему можно настраивать через свойства компонентов и переопределения.

### Проверка и принятие обновлений

Откройте **Управление библиотеками → Обновления**, чтобы найти новые редакции. Сам поиск ничего в документе не меняет. Можно сравнить текущий и обновлённый экземпляры, перейти между затронутыми экземплярами, а затем обновить:

- выбранный экземпляр;
- все экземпляры одного ассета;
- экземпляры на текущей странице;
- экземпляры на всех страницах.

Pairdraw сохраняет совместимые назначения текста, видимости и замены экземпляра. Если точного варианта больше нет, до подтверждения обновления будет показана верхняя левая замена. Применённое обновление создаёт шаг отмены.

### Локальная работа, хранилище и режим без сети

Библиотека может храниться в локальном каталоге браузера или у настроенного поставщика хранилища. При удалённой публикации используются неизменяемые объекты редакций и условно обновляемый указатель на последнюю версию, поэтому два автора не могут незаметно перезаписать изменения друг друга.

Загруженные редакции сохраняются локально. Без сети документ продолжает отображать их определения и позволяет вставлять соответствующие ассеты. Ошибки проверки целостности показываются пользователю, а не скрываются данными из кеша.

### Сохранение использующего документа

Подключения к библиотекам и материализованные определения сохраняются внутри `.fig`. После повторного открытия документа связанные экземпляры и идентификаторы редакций остаются на месте, даже если удалённая библиотека недоступна.

## Создание экземпляра

Щёлкните компонент правой кнопкой и выберите **Создать экземпляр** в контекстном меню. Новый экземпляр появится на 40 пикселей правее исходного компонента и будет выглядеть так же.

Эта команда находится только в контекстном меню; отдельной кнопки на панели инструментов нет.

## Отвязка экземпляра

Выделите экземпляр и нажмите <kbd>⌥</kbd><kbd>⌘</kbd><kbd>B</kbd> (<kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>B</kbd>), чтобы отвязать его. Экземпляр превратится в обычный фрейм без связи с основным компонентом. Все переопределения сохранятся как обычные значения.

## Преобразование во фрейм

Выделите основной компонент и нажмите <kbd>⌥</kbd><kbd>⌘</kbd><kbd>K</kbd> (<kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>K</kbd>) — те же клавиши, что и для создания компонента, — или выберите **Преобразовать во фрейм** в его контекстном меню, в меню типа слоя или в **Объект › Преобразовать во фрейм**, чтобы снова превратить его во фрейм. Если у компонента есть экземпляры, подтверждение сообщает, сколько их; преобразование отвязывает каждый экземпляр во фрейм, сохраняющий его внешний вид, включая копии, вложенные в экземпляры других компонентов. Всё изменение — один шаг отмены.

## Переход к основному компоненту

Щёлкните экземпляр правой кнопкой и выберите **Перейти к компоненту**. Pairdraw перейдёт к основному компоненту, при необходимости переключит страницу и выделит его.

## Синхронизация

После изменения компонента связанные экземпляры обновляются автоматически, как в Figma: каждое свойство, которое экземпляр не переопределил, следует за компонентом. Это размер, заливки, обводки с их толщиной, положением, окончаниями, соединениями и пунктиром, эффекты, прозрачность, режим наложения, радиусы и сглаживание углов, параметры компоновки и сетки, обрезка содержимого, общие стили и текст — от шрифта и размера до межбуквенного интервала, высоты строки, регистра, оформления, выравнивания и стилей фрагментов.

Дочерний объект экземпляра также берёт у компонента положение, поворот, отражение, привязки и маску. Если сдвинуть или повернуть объект в компоненте, он сдвинется во всех экземплярах. Если размер экземпляра отличается от размера компонента, объект размещается по своим привязкам: объект, привязанный к правому краю, сохраняет расстояние до него. Внутри автоматической компоновки объект размещает компоновка.

Синхронизация выполняется автоматически после изменения, перемещения или изменения размера объектов внутри компонента.

## Переопределения

Экземпляр может переопределять отдельные свойства, не разрывая связь с компонентом. Переопределённое в экземпляре свойство пропускается при синхронизации, а остальные продолжают обновляться из основного компонента.

### Переопределяемые свойства

Слой внутри экземпляра может переопределить имя, текст, стили фрагментов и шрифт, все визуальные и текстовые свойства из списка выше, размер, видимость и блокировку. Положение, поворот, отражение, привязки и маску переопределить нельзя: они всегда берутся из компонента. Скрипты, которые меняют положение, поворот, привязки или маску, получают ошибку Figma. Содержимое слота принадлежит экземпляру и остаётся редактируемым.

Переопределения из файла `.fig` при открытии остаются переопределениями и сохраняются так, как их записывает Figma.

### Новые дочерние объекты

Если добавить дочерний объект в компонент, его копия автоматически появится во всех существующих экземплярах. Порядок дочерних объектов в экземплярах всегда соответствует компоненту.

### Режимы переменных

Экземпляр или слой внутри него, который задаёт режим одной коллекции переменных, сохраняет этот режим и по-прежнему получает режимы компонента для всех остальных коллекций. Если сменить режим плотности основного компонента, экземпляр, в котором переключена только тема, последует за новой плотностью.

### Замена экземпляра

Выделите экземпляр, в том числе вложенный, и нажмите кнопку замены в его заголовке, чтобы показать на его месте другой компонент. В списке есть все компоненты документа; компонент, который содержал бы сам себя, недоступен. Заменённый вложенный экземпляр остаётся заменённым, когда меняется охватывающий компонент. Если замена связана со свойством замены экземпляра, заголовок показывает это свойство.

### Замена слоя внутри экземпляра

Скопируйте слой, выделите слой внутри экземпляра и нажмите <kbd>⌥</kbd><kbd>⇧</kbd><kbd>R</kbd> (<kbd>Alt</kbd> + <kbd>Shift</kbd> + <kbd>R</kbd>) или выберите **Заменить внутри экземпляра** в меню «Правка» или контекстном меню. Скопированный слой занимает место и положение выделенного как переопределение экземпляра, без отвязки: остальной экземпляр продолжает следовать за компонентом, а замена сохраняется при изменении компонента, пока компонент не удалит заменённый слой. Если выделено несколько слоёв, каждый получает свою копию. Если внутри экземпляра ничего не выделено, эти клавиши выполняют вставку с заменой.

Выделите замену и нажмите **Восстановить слой компонента** в её заголовке, чтобы вернуть слой компонента. Замены сохраняются в файлах `.fig` как данные плагина Pairdraw в экземпляре; Figma вместо них показывает слой компонента.

## Выбор дочерних объектов

Компоненты и экземпляры ведут себя как непрозрачные контейнеры: щелчок по дочернему объекту выделяет сам компонент. Дважды щёлкните компонент или экземпляр, чтобы войти внутрь и выбрать его содержимое.

## Обозначения на холсте

| Элемент | Вид |
|---------|-----|
| Подпись компонента | Фиолетовая со значком ромба, видна всегда |
| Подпись экземпляра | Фиолетовая со значком ромба, видна всегда |
| Рамка набора компонентов | Пунктирная фиолетовая обводка |

## Сочетания клавиш

| Действие | macOS | Windows / Linux |
|----------|-------|-----------------|
| Создать компонент | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>K</kbd> | <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>K</kbd> |
| Отвязать экземпляр | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>B</kbd> | <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>B</kbd> |
| Просмотр | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>↩</kbd> | <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Enter</kbd> |

## Советы

- Изменение текста внутри экземпляра создаёт переопределение, поэтому последующее изменение компонента не перезапишет этот текст.
- Наборы компонентов подходят для вариантов с несколькими параметрами, например размером, состоянием и темой.
- Публикуйте ассеты из исходного документа: опубликованные определения намеренно доступны использующим документам только для чтения.
- Перед принятием редакции проверьте обновление, особенно если в новой версии удалено точное сочетание вариантов.
- Все действия с компонентами перечислены в разделе [Контекстное меню](./context-menu).
