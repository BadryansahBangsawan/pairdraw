# Контекстное меню

Щёлкните холст правой кнопкой мыши. Если указатель находится над объектом, Pairdraw сначала выделит его. Щелчок правой кнопкой на пустом участке снимает текущее выделение.

## Копировать/Вставить как

Подменю **Копировать/Вставить как** предлагает дополнительные форматы буфера обмена для выделенных объектов:

| Действие | macOS | Windows / Linux |
|----------|-------|-----------------|
| Копировать как текст | — | — |
| Копировать как SVG | — | — |
| Копировать как PNG | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>C</kbd> | <kbd>Shift</kbd> + <kbd>Ctrl</kbd> + <kbd>C</kbd> |
| Копировать как JSX | — | — |
| Копировать как HTML | — | — |

- **Копировать как текст** копирует видимое текстовое содержимое выделения.
- **Копировать как SVG** копирует дерево объектов в виде разметки SVG.
- **Копировать как PNG** отрисовывает выделение в масштабе 2× и помещает в системный буфер обмена (можно вставить в Slack, Notion и т. д.).
- **Копировать как JSX** копирует представление Pairdraw JSX для использования с `renderJSX()`.
- **Копировать как HTML** копирует фрагмент HTML со встроенными стилями и изображениями, готовый для вставки в страницу или письмо; работает и в документах только для чтения.

## Выполнить стикер как запрос {#run-sticky-as-prompt}

Когда выделены только стикеры и хотя бы в одном есть текст, **Выполнить стикер как запрос** отправляет их текст в [чат с ИИ](/ru/programmable/ai-chat) документа со ссылкой на каждый стикер, чтобы помощник знал, из каких стикеров пришёл текст. Пункт появляется только в документах, которые вы можете редактировать. Если модель ещё не настроена, Pairdraw сначала ищет на компьютере агента для программирования, а если не находит, открывает пошаговую настройку, после чего отправляет запрос.

## Буфер обмена

| Действие | macOS | Windows / Linux |
|----------|-------|-----------------|
| Копировать | <kbd>⌘</kbd><kbd>C</kbd> | <kbd>Ctrl</kbd> + <kbd>C</kbd> |
| Вырезать | <kbd>⌘</kbd><kbd>X</kbd> | <kbd>Ctrl</kbd> + <kbd>X</kbd> |
| Вставить сюда | <kbd>⌘</kbd><kbd>V</kbd> | <kbd>Ctrl</kbd> + <kbd>V</kbd> |
| Дублировать | <kbd>⌘</kbd><kbd>D</kbd> | <kbd>Ctrl</kbd> + <kbd>D</kbd> |
| Удалить | <kbd>⌫</kbd> | <kbd>Backspace</kbd> / <kbd>Delete</kbd> |

Если ничего не выделено, действия над объектами недоступны. Вставка остаётся доступной, когда в буфере обмена есть содержимое.

## Копирование и вставка свойств

| Действие | macOS | Windows / Linux |
|----------|-------|-----------------|
| Копировать свойства | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>C</kbd> | <kbd>Alt</kbd> + <kbd>Ctrl</kbd> + <kbd>C</kbd> |
| Вставить свойства | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>V</kbd> | <kbd>Alt</kbd> + <kbd>Ctrl</kbd> + <kbd>V</kbd> |

Обе команды находятся в подменю **Копировать/Вставить как**.

- **Копировать свойства** помещает выделенный слой в системный буфер обмена так же, как Figma, с пометкой, чтобы обычная вставка его игнорировала.
- **Вставить свойства** применяет внешний вид единственного слоя из буфера обмена ко всем выделенным слоям, включая заблокированные, одним шагом отмены. Команда принимает копию, сделанную командой «Копировать свойства» или обычным копированием, здесь или в Figma.
- Внешний вид — это заливки, обводки, эффекты, прозрачность, режим наложения, радиус углов, а также связанные стили и переменные. Между фреймами переносятся и автоматическая компоновка с сетками макета, между текстовыми слоями — стиль текста. Положение, размер, поворот, имя и содержимое никогда не меняются, а свойства, которые в текстовом слое различаются у разных символов, остаются нетронутыми.

## Порядок наложения

| Действие | Клавиша |
|----------|---------|
| На передний план | <kbd>]</kbd> |
| На задний план | <kbd>[</kbd> |

Команды перемещают выделенный объект в начало или конец списка дочерних объектов его родителя.

## Группы и автоматическая компоновка

| Действие | macOS | Windows / Linux |
|----------|-------|-----------------|
| Сгруппировать | <kbd>⌘</kbd><kbd>G</kbd> | <kbd>Ctrl</kbd> + <kbd>G</kbd> |
| Разгруппировать | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>G</kbd> | <kbd>Shift</kbd> + <kbd>Ctrl</kbd> + <kbd>G</kbd> |
| Добавить авто-раскладку | <kbd>⇧</kbd><kbd>A</kbd> | <kbd>Shift</kbd> + <kbd>A</kbd> |

- **Сгруппировать** требует не менее двух выделенных объектов.
- **Разгруппировать** появляется, когда выделена группа; её дочерние объекты переходят к родителю группы.
- **Добавить авто-раскладку** оборачивает выделение в новый фрейм с [автоматической компоновкой](./auto-layout).

## Компоненты

Действия с компонентами показаны фиолетовым цветом, как и сами компоненты.

| Действие | macOS | Windows / Linux | Доступно для |
|----------|-------|-----------------|--------------|
| Создать компонент | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>K</kbd> | <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>K</kbd> | Любое выделение |
| Создать набор компонентов | — | — | Не менее двух компонентов |
| Создать экземпляр | — | — | Компоненты (без сочетания клавиш) |
| Перейти к компоненту | — | — | Экземпляры |
| Отвязать экземпляр | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>B</kbd> | <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>B</kbd> | Экземпляры |

Подробнее о работе с компонентами — в разделе [Компоненты](./components).

## Видимость и блокировка

| Действие | macOS | Windows / Linux |
|----------|-------|-----------------|
| Скрыть / Показать | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>H</kbd> | <kbd>Shift</kbd> + <kbd>Ctrl</kbd> + <kbd>H</kbd> |
| Заблокировать / Разблокировать | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>L</kbd> | <kbd>Shift</kbd> + <kbd>Ctrl</kbd> + <kbd>L</kbd> |

Название пункта зависит от текущего состояния объекта: «Скрыть» для видимого объекта, «Показать» для скрытого.

## Переместить на страницу

Подменю **Переместить на страницу** содержит все страницы, кроме текущей. Выберите страницу, чтобы перенести выделенные объекты на её холст.

## Советы

- На пустом холсте контекстное меню даёт доступ к вставке — так удобно поместить содержимое в нужное место.
- Команды для компонентов появляются только в подходящем контексте (например, «Создать экземпляр» — только для компонентов).
- Рядом с командами указаны сочетания клавиш, поэтому меню удобно использовать, чтобы узнать незнакомые сочетания.
