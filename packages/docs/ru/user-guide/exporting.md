# Экспорт и файлы

Pairdraw экспортирует отдельные объекты как изображения, SVG или самостоятельные документы `.fig`. Редактор открывает полные документы `.fig` и `.pen`.

## Экспорт изображений

Выделите объект и откройте раздел «Экспорт» на панели свойств.

### Настройки

- **Масштаб:** 0,5×, 0,75×, 1×, 1,5×, 2×, 3× или 4×. Для SVG масштаб не показывается, поскольку векторная графика не зависит от разрешения.
- **Формат:** PNG с прозрачным фоном, JPG с белым фоном, WEBP с прозрачным фоном, SVG (вектор), PDF или HTML.

**Файл → Экспорт выделения…** экспортирует выделение в PNG, SVG или `.fig`, а <kbd>⇧</kbd><kbd>⌘</kbd><kbd>E</kbd> сразу экспортирует его в PNG.

Приложение не экспортирует в PowerPoint (`.pptx`) и draw.io. [CLI](/reference/cli#export) по-прежнему экспортирует оба формата: `pairdraw export design.fig -f pptx` или `-f drawio`.

Для одного объекта можно добавить несколько настроек экспорта, чтобы за один раз получить его в разных масштабах или форматах. Предварительный просмотр на клетчатом фоне показывает будущий результат.

### Способы экспорта

| Способ | macOS | Windows / Linux |
|--------|-------|-----------------|
| Сочетание клавиш (PNG) | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>E</kbd> | <kbd>Shift</kbd> + <kbd>Ctrl</kbd> + <kbd>E</kbd> |
| Контекстное меню | Правая кнопка → Экспорт… | Правая кнопка → Экспорт… |
| Панель свойств | Кнопка «Экспорт» | Кнопка «Экспорт» |

В приложении для компьютера путь выбирается в системном диалоге. В браузере файл загружается обычным способом.

## HTML, PDF и качество

- **У строк JPG и WEBP** есть поле качества от 1 до 100 (по умолчанию 90), которое сохраняется вместе со слоем.
- **PDF** при нескольких выделенных слоях создаёт один файл PDF со страницей на каждый слой в порядке выделения, каждая размером со свой слой.
- **Файл › Экспортировать фреймы в PDF…** сохраняет фреймы страницы в один файл PDF, по странице на фрейм в порядке слоёв, каждая размером со свой фрейм. Фреймы внутри секций учитываются, отдельные фигуры, тексты и группы — нет. Если слои выделены, экспортируются только они.
- **HTML** записывает слой как веб-страницу. Кнопка параметров рядом с форматом определяет, включать ли каркас HTML (целая страница или фрагмент для вставки), оформлять ли через CSS или Tailwind, встраивать ли изображения или сохранять их отдельными файлами (вместе в `.zip`), и записывать ли в атрибуты имена слоёв (`data-name`, по умолчанию включено) и ID слоёв (`data-pairdraw-node-id`, по умолчанию выключено). Вид HTML на панели «Код» экспортирует так же, с показанным там оформлением.
- На панели «Код» компоненты Vue и React могут брать значки из Lucide, Heroicons или Font Awesome вместо Iconify, а компоненты React — ещё и из React Icons; значок, которого нет в пакете, остаётся в Iconify.

## Копировать/Вставить как

Помимо экспорта в файл, выделение можно поместить в буфер обмена в нескольких форматах через контекстное меню (правая кнопка → Копировать/Вставить как):

| Действие | macOS | Windows / Linux |
|----------|-------|-----------------|
| Копировать как текст | — | — |
| Копировать как SVG | — | — |
| Копировать как PNG | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>C</kbd> | <kbd>Shift</kbd> + <kbd>Ctrl</kbd> + <kbd>C</kbd> |
| Копировать как JSX | — | — |

- Текст копируется из видимого содержимого выделенных объектов.
- SVG копирует выделение в виде разметки SVG (можно вставить в редактор кода, Inkscape и т. д.).
- PNG отрисовывается в масштабе 2× и копируется в буфер обмена (готов для вставки в Slack, Notion и т. д.).
- JSX совместим с `renderJsx()` Pairdraw.

## Документы .fig и .pen

Для полных документов Pairdraw использует формат `.fig` — тот же бинарный формат, что и у Figma, а также открывает документы `.pen`.

### Открытие

| Действие | macOS | Windows / Linux |
|----------|-------|-----------------|
| Открыть файл | <kbd>⌘</kbd><kbd>O</kbd> | <kbd>Ctrl</kbd> + <kbd>O</kbd> |

Открывается диалог выбора с фильтром по файлам `.fig` и `.pen`. В настольном приложении используется системный диалог.

Документ `.fig`, `.pen` или другого поддерживаемого формата можно также перетащить в окно — он откроется в новой вкладке. Изображения и файлы SVG, перетащенные на холст, вместо этого помещаются в документ, а для любого другого файла появляется сообщение, что его нельзя открыть.

Документ `.pen`, импортирующий библиотеки `.pen`, открывается с используемыми компонентами библиотек, прочитанными из файлов по путям относительно документа. В документе это компоненты библиотеки только для чтения; изменяйте их в самой библиотеке. Браузер не может читать файлы рядом с документом, поэтому там эти компоненты показаны пунктирными заглушками, а сообщение называет библиотеки; откройте файл в настольном приложении или через CLI, чтобы загрузить их. Настольное приложение читает библиотеки не выше двух папок над документом, но никогда из домашней папки или выше и не по ссылкам; файл, перетащенный в окно, их не читает, поэтому откройте его через Файл > Открыть…. CLI читает библиотеки внутри рабочего каталога. Узлы скриптов и браузера, которые Pairdraw не запускает, тоже открываются как заглушки, сохраняющие файл скрипта или адрес страницы.

### Сохранение

| Действие | macOS | Windows / Linux |
|----------|-------|-----------------|
| Сохранить | <kbd>⌘</kbd><kbd>S</kbd> | <kbd>Ctrl</kbd> + <kbd>S</kbd> |
| Сохранить как | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>S</kbd> | <kbd>Shift</kbd> + <kbd>Ctrl</kbd> + <kbd>S</kbd> |

**Сохранить** перезаписывает текущий файл без диалога, если Pairdraw по-прежнему имеет разрешение на запись. **Сохранить как** позволяет выбрать новый путь.

В Chrome и Edge браузер использует File System Access API. В других браузерах, включая Safari, файл загружается через механизм скачивания.

Сохранённый файл сжимается и содержит миниатюру для предпросмотра в файловом менеджере.

Когда ничего не выделено, раздел **Документ** на панели «Дизайн» задаёт степень сжатия документа. **Быстрое** соответствует сохранению в самой Figma. **Компактнее** и **Максимальное** уменьшают файл, но сохраняют его дольше; сильнее всего это заметно на больших документах и меньше всего — на файлах, состоящих в основном из изображений. Выбор хранится в файле, и Figma открывает все три варианта.

### Совместимость с Figma

Файлы, экспортированные из Pairdraw, можно открыть в Figma, а документы Figma — в Pairdraw. Формат `.fig` сохраняет типы объектов, свойства, заливки, обводки, эффекты, векторные данные и параметры компоновки.

## Советы

- Для экранов с высокой плотностью пикселей используйте масштаб 2× или 3×.
- JPG всегда получает белый фон. Для прозрачности выберите PNG или WEBP.
- SVG подходит для последующего редактирования в Illustrator, Inkscape или коде.
- Миниатюра в экспортированных файлах `.fig` позволяет видеть предпросмотр в файловом менеджере и в окне выбора файлов Figma.
