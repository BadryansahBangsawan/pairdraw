# Редактирование текста

Pairdraw позволяет создавать текстовые объекты и редактировать форматированный текст непосредственно на холсте.

## Создание текста

Нажмите <kbd>T</kbd>, затем щёлкните по холсту. Появится пустой текстовый объект с мигающим курсором — можно сразу начинать ввод.

## Редактирование на холсте

Дважды щёлкните существующий текстовый объект. Синяя рамка показывает, что включён режим редактирования. Щёлкните за пределами объекта, чтобы применить изменения и выйти.

Текст отображается средствами самого холста; отдельного видимого поля ввода поверх него нет.

## Перемещение курсора

| Действие | macOS | Windows / Linux |
|----------|-------|-----------------|
| На один символ влево или вправо | <kbd>←</kbd> / <kbd>→</kbd> | <kbd>←</kbd> / <kbd>→</kbd> |
| На строку вверх или вниз | <kbd>↑</kbd> / <kbd>↓</kbd> | <kbd>↑</kbd> / <kbd>↓</kbd> |
| На одно слово | <kbd>⌥</kbd><kbd>←</kbd> / <kbd>⌥</kbd><kbd>→</kbd> | <kbd>Ctrl</kbd> + <kbd>←</kbd> / <kbd>Ctrl</kbd> + <kbd>→</kbd> |
| В начало или конец строки | <kbd>⌘</kbd><kbd>←</kbd> / <kbd>⌘</kbd><kbd>→</kbd> | <kbd>Home</kbd> / <kbd>End</kbd> |

Удерживайте <kbd>Shift</kbd> вместе с клавишей движения, чтобы расширить выделение текста.

## Выделение текста

- Щёлкните внутри текста, чтобы установить курсор.
- Щёлкните и перетащите указатель, чтобы выделить диапазон.
- Дважды щёлкните слово, чтобы выделить его.
- Трижды щёлкните текст, чтобы выделить всё содержимое объекта.

## Форматирование

Форматирование применяется к выделенному диапазону. Если диапазон не выделен, кнопка меняет стиль всего текстового объекта.

| Действие | macOS | Windows / Linux |
|----------|-------|-----------------|
| Полужирное начертание | <kbd>⌘</kbd><kbd>B</kbd> | <kbd>Ctrl</kbd> + <kbd>B</kbd> |
| Курсив | <kbd>⌘</kbd><kbd>I</kbd> | <kbd>Ctrl</kbd> + <kbd>I</kbd> |
| Подчёркивание | <kbd>⌘</kbd><kbd>U</kbd> | <kbd>Ctrl</kbd> + <kbd>U</kbd> |

Зачёркивание включается кнопкой **S** в разделе «Типографика». Отдельного сочетания нет, поскольку <kbd>⌘</kbd><kbd>S</kbd> используется для сохранения.

Стиль хранится для каждого символа. Если вводить текст между фрагментами с полужирным и обычным начертанием, новые символы наследуют стиль предыдущего фрагмента.

Форматирование также можно изменить кнопками **B / I / U / S** в разделе «Типографика».

## Ссылки

Текст может содержать ссылку на веб-страницу или адрес электронной почты — на всём тексте или на выделенных символах. Когда слой выделен, выберите **Добавить ссылку** в разделе «Типографика» на панели свойств, в **Текст → Добавить ссылку** в строке меню или в контекстном меню холста. Редактор ссылки открывается под текстом: введите адрес — голый домен или `имя@хост` получает свои `https://` или `mailto:` — и нажмите <kbd>Enter</kbd>, чтобы применить его, либо <kbd>Escape</kbd>, чтобы закрыть без изменений. Позже этот же редактор изменяет ссылку и удаляет её.

⌘-щелчок (Ctrl-щелчок в Windows и Linux) по ссылке на холсте открывает её, как и щелчок по ней в предпросмотре.

## Редактирование

| Действие | macOS | Windows / Linux |
|----------|-------|-----------------|
| Удалить предыдущее слово | <kbd>⌥</kbd><kbd>⌫</kbd> | <kbd>Ctrl</kbd> + <kbd>Backspace</kbd> |
| Удалить до начала строки | <kbd>⌘</kbd><kbd>⌫</kbd> | — |
| Вырезать | <kbd>⌘</kbd><kbd>X</kbd> | <kbd>Ctrl</kbd> + <kbd>X</kbd> |
| Копировать | <kbd>⌘</kbd><kbd>C</kbd> | <kbd>Ctrl</kbd> + <kbd>C</kbd> |
| Вставить | <kbd>⌘</kbd><kbd>V</kbd> | <kbd>Ctrl</kbd> + <kbd>V</kbd> |

## Изменение размера и обрезка

Параметр **Изменение размера** в разделе «Раскладка» задаёт, как текстовое поле следует за своим содержимым:

- **Автоматическая ширина** — поле растёт, чтобы каждая строка помещалась в одну строку (автоподбор ширины и высоты Figma).
- **Автоматическая высота** — ширина остаётся фиксированной, а поле растёт в высоту, когда текст переносится.
- **Фиксированный** — поле сохраняет размер, который вы ему задали.

**Обрезка** в разделе «Типографика» отсекает текст, выходящий за поле: **Многоточие в конце** добавляет многоточие, а **Максимум строк** ограничивает, сколько строк рисуется перед обрезкой. Обрезаемый текст сохраняет своё поле в автоматической компоновке, поэтому фрейм, подогнанный по содержимому, задаёт размер по этому полю, а не сжимается до нуля.

## Выбор шрифта

Откройте панель выбора шрифта в разделе «Типографика» на панели свойств, чтобы сменить семейство шрифта. Возможности панели:

- **Поиск** сокращает список по мере ввода.
- **Предварительный просмотр** показывает название каждого шрифта его собственным начертанием.
- **Виртуальная прокрутка** позволяет без задержек работать с большими каталогами.
- При открытии список прокручивается к текущему семейству и выделяет его.

## Переменные для семейства шрифта

Семейство шрифта может браться из строковой переменной. В разделе «Типографика» выберите **Применить переменную к гарнитуре** рядом с семейством и укажите переменную, значение которой — название семейства шрифта. После этого текст следует за переменной: переключение режима переменной или изменение её значения меняет семейство, и редактор загружает шрифты нового семейства. Выбор шрифта на панели выбора шрифта отвязывает переменную и задаёт этот шрифт напрямую.

## Текст по контуру

Импортированные из Figma слои с текстом по контуру сохраняют изогнутое расположение символов. Их текст и типографику можно редактировать, слои можно выделять и менять их размер, а результат сохранять и экспортировать с сохранением расположения по контуру. Это поддержка уже существующих импортированных слоёв с текстом по контуру, а не отдельный инструмент для привязки произвольного текста к новому контуру.

## Начертание шрифта

Начертание меняется в разделе «Типографика» на панели свойств. Доступные начертания зависят от выбранного семейства, например Regular, Medium, Bold и Black.

## Вариативные шрифты

Если шрифт вариативный, как Inter, раздел «Типографика» показывает его оси (толщину, оптический размер, ширину и другие) со значениями, в которых он рисуется. Введённое или перетянутое значение задаёт ось; выбор толщины, наклона или семейства возвращает оси этого начертания. Оптический размер показывает **Авто**, пока следует за размером шрифта; введённое значение или **Фиксированный** в его меню фиксирует его, а **Авто** снова включает следование.

## Источники шрифтов

- **По умолчанию:** Inter загружается автоматически.
- **Настольное приложение:** системные шрифты и включённые каталоги Google Fonts, Fontsource, Bunny Fonts и Fontshare.
- **Браузер:** системные шрифты доступны в Chrome и Edge с разрешением на доступ к локальным шрифтам. Включённые поставщики Fontsource, Bunny Fonts и Fontshare могут загружать онлайн-шрифты, если позволяют доступ к сети и правила CORS браузера; Google Fonts в браузерной версии Pairdraw отключён.
- **Загруженные шрифты:** приложение сохраняет скачанные начертания для повторного использования на этом компьютере.

Доступ к системным шрифтам и онлайн-провайдеры настраиваются в разделе «Настройки › Шрифты», который открывается нажатием на шестерёнку рядом с семейством шрифтов; в настольном приложении там же управляются скачанные шрифты и резервные наборы.

## Шрифты документа

Перетащите файл TTF, OTF, WOFF или WOFF2 на холст, чтобы добавить его семейство в сам документ: оно появится в выборе шрифтов, сохранится в файле `.fig` и попадёт в веб-экспорты и Storybook. Шрифты, которые несёт документ, не требуют установки и поставщика.

## Отсутствующие шрифты и замены

Если нужное семейство или начертание загрузить не удалось, Pairdraw показывает предупреждение над редактором и не выдаёт отображение с заменой за точное воспроизведение типографики.

Раскройте предупреждение, чтобы увидеть затронутые начертания и выбранные замены. Кнопка **Выбрать слои** выделяет соответствующие текстовые объекты. После изменения сетевого доступа, разрешения на локальные шрифты или настроек поставщиков нажмите **Повторить загрузку шрифтов**.

Начертание может быть синтезировано из другого загруженного начертания того же семейства. Если отсутствует всё семейство, используется Inter, когда он доступен.

## Советы

- Список шрифтов загружается при запуске, поэтому панель открывается без задержки.
- Поддерживается ввод через IME для китайского, японского и корейского языков.
- Форматирование сохраняется при открытии и записи `.fig`.
- Переопределения текста внутри экземпляров компонентов описаны в разделе [Компоненты](./components).
