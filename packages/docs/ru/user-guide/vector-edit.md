# Редактирование векторов

В режиме редактирования векторов изменяется **геометрия** кривой: положение опорных точек, форма сегментов и рычаги Безье.
В этом режиме вы редактируете сам контур, а не обычные преобразования объекта.

## Вход в режим

- Выберите векторный объект инструментом «Выделение».
- **Дважды щёлкните кривую**.

Так включается редактирование геометрии выделенного вектора.

## Выход из режима

- Нажмите <kbd>Escape</kbd>.
- Щёлкните пустое место на холсте.
- Или перейдите в другой режим редактирования.

## Отличия режима

- Обычная рамка преобразования объекта отключается.
- Становится доступным редактирование опорных точек, сегментов и рычагов.
- У углов рамки слоя указатель не переключается на изменение размера и поворот; у рамки преобразования выбранных точек — переключается (см. [Преобразование выбранных точек](#transform-selected-points)).

## Основные действия

### Перемещение опорной точки

- Перетащите опорную точку.
- Связанные сегменты и форма контура обновляются во время движения.

### Изменение рычага Безье

- Перетащите рычаг опорной точки.
- По умолчанию поведение зависит от текущего сочетания рычагов этой точки.

### Выделение и перемещение сегмента

- Щёлкните сегмент, чтобы выделить его. Сегмент становится синим, и в его середине появляется маркер; его опорные точки остаются невыделенными.
- <kbd>Shift</kbd> + щелчок добавляет сегмент к выделению или убирает из него уже выделенный.
- Перетащите сегмент, чтобы переместить две соединяемые им опорные точки вместе с остальным выделением.

### Выделение рамкой

- Перетащите по пустому месту, чтобы выделить опорные точки внутри прямоугольника и сегменты между ними.
- <kbd>Shift</kbd> + перетаскивание добавляет их к выделению.

### Выделение области

- Наведите указатель на залитую область: область под ним заштриховывается диагональными линиями.
- Щёлкните внутри, чтобы выделить область и все её точки; перетащите, чтобы переместить её.
- <kbd>Shift</kbd> + щелчок добавляет область к выделению.

### Удаление опорных точек и сегментов

- Нажмите <kbd>Delete</kbd> или <kbd>Backspace</kbd>, чтобы удалить выделенное.
- Удалённая опорная точка забирает с собой свои сегменты.
- Удалённый сегмент забирает только те опорные точки, которые остаются без связей, поэтому удаление среднего сегмента контура разделяет его надвое.
- Если удалить всё, удаляется и слой.

## Разрезание, соединение и изменение формы

| Действие | macOS | Windows / Linux |
| -------- | ----- | --------------- |
| Инструмент разрезания | <kbd>X</kbd> | <kbd>X</kbd> |
| Гладкая или угловая точка | Двойной щелчок по точке | Двойной щелчок по точке |
| Выпрямить сегмент | <kbd>Cmd</kbd> + двойной щелчок | <kbd>Ctrl</kbd> + двойной щелчок |
| Изогнуть сегмент | <kbd>Cmd</kbd> + перетаскивание сегмента | <kbd>Ctrl</kbd> + перетаскивание сегмента |
| Изогнуть, не трогая соседей | <kbd>Cmd</kbd> + <kbd>Option</kbd> + перетаскивание | <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + перетаскивание |
| Соединить две конечные точки | <kbd>Cmd</kbd> + <kbd>J</kbd> | <kbd>Ctrl</kbd> + <kbd>J</kbd> |
| Дублировать точки | <kbd>Option</kbd> + перетаскивание | <kbd>Alt</kbd> + перетаскивание |
| Сдвинуть точки | Стрелки | Стрелки |

- **Инструмент разрезания:** нажмите <kbd>X</kbd>, затем щёлкните сегмент, чтобы разрезать его в этом месте, или точку, чтобы разъединить сходящиеся в ней сегменты. Кривые сохраняют форму, а разрезанная замкнутая фигура перестаёт заливаться. <kbd>X</kbd> ещё раз, <kbd>Escape</kbd> или клавиша другого инструмента выключает его.
- **Гладкая или угловая:** двойной щелчок по угловой точке добавляет ей рычаги вдоль линии между её соседями, а двойной щелчок по гладкой точке убирает её рычаги.
- **Выпрямление:** <kbd>Cmd</kbd>/<kbd>Ctrl</kbd> + двойной щелчок по изогнутому сегменту убирает оба его рычага.
- **Соединение:** выделите две конечные точки и нажмите <kbd>Cmd</kbd>/<kbd>Ctrl</kbd> + <kbd>J</kbd>. Совпадающие точки становятся одной, а удалённые соединяются прямым сегментом. Соединение двух концов одного контура замыкает и заливает его. Во время редактирования контура это сочетание соединяет точки, а не открывает чат.
- **Дублирование:** удерживайте <kbd>Option</kbd>/<kbd>Alt</kbd> и перетащите выделенные точки или сегменты, чтобы перетащить их копию. Копия одиночной точки остаётся соединённой с ней, поэтому перетаскивание продолжает контур.
- **Сдвиг:** клавиши со стрелками сдвигают выбранные точки на расстояние сдвига из «Настройки → Редактор», а <kbd>Shift</kbd> + стрелка — на большое расстояние сдвига.
- **Изгиб:** <kbd>Cmd</kbd>/<kbd>Ctrl</kbd> + перетаскивание сегмента изгибает его так, что захваченное место следует за указателем. Гладкая конечная точка остаётся гладкой, а её второй рычаг поворачивается вместе с ней. Добавьте <kbd>Option</kbd>/<kbd>Alt</kbd>, чтобы рычаги соседних сегментов остались на месте; конечные точки тогда становятся угловыми.

## Преобразование выбранных точек {#transform-selected-points}

Когда выбраны две точки или два сегмента, вокруг них появляется рамка преобразования.

- Перетащите угол или сторону, чтобы масштабировать выбранные точки от противоположной стороны. С <kbd>Shift</kbd> пропорции сохраняются, а с <kbd>Option</kbd>/<kbd>Alt</kbd> масштаб идёт от центра.
- Перетащите чуть за пределами угла, чтобы повернуть их вокруг центра рамки. С <kbd>Shift</kbd> поворот идёт шагами по 15°.
- Точки и сегменты под указателем можно перетаскивать и поверх рамки, а каждое преобразование отменяется одним шагом.

## Модификаторы при перетаскивании рычага

| Режим | macOS | Windows / Linux |
|-------|-------|-----------------|
| Непрерывный (гладкий / непрерывный) | <kbd>Cmd</kbd> + перетаскивание | <kbd>Ctrl</kbd> + перетаскивание |
| Угловой (независимые рычаги) | <kbd>Option</kbd> + перетаскивание | <kbd>Alt</kbd> + перетаскивание |
| Фиксация направления (только длина) | <kbd>Shift</kbd> + перетаскивание | <kbd>Shift</kbd> + перетаскивание |

### Непрерывный режим: <kbd>Cmd</kbd>/<kbd>Ctrl</kbd> + перетаскивание

- Активный рычаг остаётся на одной прямой со вторым.
- Изменяется только длина активного рычага.
- Режим подходит для плавного перехода без излома.

### Угловой режим: <kbd>Option</kbd>/<kbd>Alt</kbd> + перетаскивание

- Активный рычаг изменяется независимо.
- Второй рычаг остаётся на месте.
- Режим создаёт резкий угловой переход.

### Фиксация направления: <kbd>Shift</kbd> + перетаскивание

Для точек с сочетанием рычагов **Continuous** или **Symmetric**:

- направление рычага фиксируется в положении **до начала текущего перетаскивания**;
- перетаскивание меняет только длину рычага (или обоих рычагов, в зависимости от сочетания).

## Изменение изгиба перетаскиванием точки

Если перетаскивать опорную точку с нажатой <kbd>Cmd</kbd>/<kbd>Ctrl</kbd>, редактор выбирает целевой рычаг по **направлению присоединения сегмента** к этой точке, а не по расстоянию до ближайшей соседней точки.
Это работает и для точек с несколькими ответвлениями в векторной сети: после выбора целевой рычаг не меняется до конца текущего перетаскивания.

## Инструмент «Перо» в режиме редактирования

Если активно «Перо»:

- **щёлкните сегмент**, чтобы вставить новую опорную точку и разделить сегмент;
- **щёлкните конечную точку открытого контура**, чтобы продолжить рисование от неё;
- **Option/Alt + щелчок по опорной точке** удаляет её, если топология это допускает.

Создание и замыкание контуров описано в разделе [Инструмент «Перо»](./pen-tool.md).

## Пример работы

1. Создайте фигуру инструментом «Перо».
2. Дважды щёлкните кривую, чтобы перейти в режим редактирования векторов.
3. Переместите опорные точки и уточните силуэт.
4. Измените рычаги:
   - с <kbd>Cmd</kbd>/<kbd>Ctrl</kbd> для плавного непрерывного перехода;
   - с <kbd>Option</kbd>/<kbd>Alt</kbd> для независимого изменения;
   - с <kbd>Shift</kbd> только для изменения длины.
5. Нажмите <kbd>Escape</kbd>, чтобы выйти.
